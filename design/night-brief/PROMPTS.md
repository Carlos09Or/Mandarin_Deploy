# Night doors and paths: brief for the image agent

Send each prompt together with the attached image of the same number. Ask for the output named as shown.

## 01. Attach `01-airport-DAY.png`  →  save result as `01-airport-NIGHT.png`

```
Attached is ONE sheet with the DAY versions of a lesson door in 3 states, left to right: closed | half open | wide open.
Redraw the SAME three pictures as a NIGHT version.

KEEP IDENTICAL: the exact composition, silhouette, camera angle, proportions, door shape, every object (plants, rocks, shells, vines, clouds, etc.), the position and size of the round plaque, and where the door sits in each of the 3 states. Same polished, soft-gradient illustrated map style with soft rim highlights. Do not redesign anything.

CHANGE ONLY THE LIGHTING AND COLOUR to a calm, warm-cool night (not scary, not pitch dark):
- cool moonlight from the upper left: blue-violet shadows, pale silver rim light on stone edges
- door wood and paint shift to deeper navy/indigo/umber versions of the same colour
- brass ring, hinges and the door frame glow slightly warmer, as if a small lantern lights them
- plants become deep teal-green with a moonlit edge
- any sky element (clouds etc.) becomes lilac-navy with a soft moonlit edge
- anything that can have lights gets them lit (windows, lamps)
- in the HALF and OPEN states, warm golden light spills out of the door onto the doorstep, brighter than by day, so the open door is the warm focus
- the plaque stays a BLANK round disc, with no text, numbers or symbols

SPECIFIC: the airplane keeps its exact shape and colours but gets lit cabin windows and small red/green navigation lights; clouds are moonlit lilac-navy.

OUTPUT: one image with the 3 states side by side (closed | half | open), same layout and scale as the attached sheet, on a flat PURE WHITE background (#FFFFFF), with no ground shadow or glow spreading outside the door's own silhouette, so it can be cut out cleanly. No text anywhere.
```
